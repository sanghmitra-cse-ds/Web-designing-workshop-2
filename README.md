# GTA V Clone Website (Web Designing Workshop – 2)

This project is a GTA V themed website clone created as part of the Web Designing Workshop – 2.
The objective of this project is to practice frontend development by recreating the look and feel of the Grand Theft Auto V (GTA V) website using basic web technologies.

The project focuses on implementing layout design, styling, and interactive components inspired by the official GTA V theme.

## 🎮 Project Overview

The GTA V Clone is a static frontend project that replicates the design aesthetics of the GTA V website. It demonstrates how HTML, CSS, and JavaScript can be used to build visually appealing and responsive web pages.

Key features of the project include:

* GTA V themed landing page
* Styled navigation bar
* Game-inspired UI elements
* Responsive layout
* Interactive sections using JavaScript

---

## 🛠 Technologies Used

* HTML5 – Page structure
* CSS3 – Styling and layout design

## 🚀 How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/sanghmitra-cse-ds/Web-designing-workshop-2.git
```

2. Navigate to the project directory

```bash
cd Web-designing-workshop-2
```

3. Open the project

Simply open `index.html` in your browser.

You can also run it using VS Code Live Server for a better development experience.
